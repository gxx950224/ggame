# ggame 皮肤：DSH 网页背景图

ggame 整合包内置**皮肤功能**：设置一个背景图，DSH 网页（深色主题）会以该图为底、叠加半透明暗色保证可读性，营造沉浸式体验。

## 使用方法

1. 打开 **设置 → 插件 → 插件配置 → 背包**。
2. 在 `backgroundImage` 字段填入背景图来源，二选一：
   - **本地图片路径**：如 `C:\Users\me\Pictures\ggame-bg.png`
   - **网络图片 URL**：如 `https://example.com/bg.jpg`（需可访问）
3. 重启 DSH（或重新加载页面）即可生效。
4. 留空 = 恢复默认深色背景。

> 推荐尺寸：16:9 横版，1920×1080 或更高；画面主体靠边/居中留白，避免干扰右侧物品栏与左侧会话列表的阅读。
