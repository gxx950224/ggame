# ggame 皮肤：DSH 网页背景图

ggame 整合包内置**皮肤功能**：DSH 网页（深色主题）以背景图为底、叠加半透明暗色遮罩保证可读性，营造沉浸式体验。

## 使用方法（整合包用户，开箱即用）

背景图**随整合包自带**（发布时已放入 `packages/backpack/skin/ggame-bg.png`）。下载整合包安装后，DSH 网页会自动显示背景图，无需任何配置。

**单独安装 `@ggame/backpack` / `@ggame/quest` 单体插件时没有背景图**（保持默认深色主题）。

## 自定义 / 替换背景图

- **换图**：直接用你的图片替换 `packages/backpack/skin/ggame-bg.png`（也支持 `.jpg/.jpeg/.webp`，文件名必须为 `ggame-bg.*`），重新部署整合包即可。
- **临时指定**：若你的部署支持插件配置，可在 `backgroundImage` 填本地图片路径或 http(s) URL（优先于内置皮肤图）；留空则回退到内置皮肤图（存在时）或默认深色背景。

> 推荐尺寸：16:9 横版，1920×1080 或更高；画面主体靠边、中央留白，避免干扰右侧物品栏与左侧会话列表的阅读。

## 背景图提示词（豆包等 AI 生图工具）

直接复制以下提示词发给豆包生成：

> 一张用于 DeepSeek Harness 网页界面背景的暗黑奇幻风壁纸，16:9 横版，1920x1080。画面为远古石质大殿与泛黄羊皮纸质感融合的深色调场景，主色调墨黑、暗金、深褐，点缀少量暗绿魔法符文。四边与角落有魔兽世界风格的暗金纹饰（缠绕藤蔓、古朴符文、旧地图卷轴边角），中央大面积留白且整体亮度低，方便文字阅读。质感厚重，光影柔和，无任何文字、无 Logo、无主体人物，仅作网页背景使用。
